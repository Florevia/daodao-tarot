# 元素、花色与数字

只在这副牌真的出现倾斜时才用，不要每张都报元素。

## 相生相克（一种固定用法）

- 火（权杖）与风（宝剑）互相加强：行动和想法一起变快，也可能一起变冲。
- 水（圣杯）与土（星币）互相加强：情感落到日子、钱和身体上，比较稳，也可能变慢。
- 火与水彼此削弱：想冲的心和想感受的心拧着。
- 风与土彼此削弱：想清楚和想做实在的事互相拖。
- 同花色堆在一起：这件事几乎只发生在一个领域。心里知道就好，正文写具体的事，不要报元素有多重。

## 大阿尔卡纳的密度

这些只留在心里，不要写进正文。若身份、选择、周期比日常事务响，就用具体的牌来说；若几乎都是小牌，这是可以动手的实务，不要上升成命运。不要写“大牌”“几张”“占了”“居多”“很重”“在流失”。

## 重复的数字

同一个数字出现两次或以上，是同一种课题换了领域。例如两个五，冲突、失落或匮乏在不同牌上各说一次，要按花色分开，不能写成“凡是五都是冲突”。王牌重复是多处开始。十重复是多处到了尽头或过载。宫廷牌重复是好几处都在讲人的角色。
